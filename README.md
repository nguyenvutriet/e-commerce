## 📖 Introduction

**E-Commerce** is a full-stack online shopping application built with **React** and **Java Spring Boot**.

The project follows a client-server architecture, where the frontend communicates with the backend through RESTful APIs. PostgreSQL is used to store application data, while Spring Security and JWT provide authentication and authorization mechanisms.

The platform aims to deliver a convenient shopping experience, including product discovery, customer accounts, shopping cart management, order processing, and payment integration.

## ✨ Some Features

| Feature | Description |
|:---|:---|
| 🛍️ **Product Browsing** | Explore products and view detailed product information. |
| 🔐 **Authentication & Authorization** | Secure application endpoints using Spring Security and JWT. |
| 🛒 **Shopping Cart** | Manage selected products before checkout. |
| 📦 **Order Management** | Support the shopping and checkout workflow. |
| 💳 **Online Payment** | Integrate Stripe for payment processing. |
| 🧑‍💼 **Product Administration** | Backend support for managing product data. |
| 🔗 **RESTful API** | Connect the React frontend and Spring Boot backend through HTTP APIs. |
| 📚 **API Documentation** | Document APIs using OpenAPI / Swagger UI. |
| ✅ **Input Validation** | Validate incoming requests on the backend. |
| 📱 **Responsive UI** | Build a modern interface with React and UI libraries. |
